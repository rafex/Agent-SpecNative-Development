# ASN — Agente SpecNative

ASN acompaña a programadores que usan SpecNative: ayuda a aclarar una iniciativa,
prepara propuestas de documentos y las aplica sólo después de una aprobación
explícita. El repositorio conserva la fuente de verdad; el agente no sustituye
las specs, tareas ni decisiones versionadas.

## Empieza aquí

- [Primeros pasos](getting-started.md): instala ASN, configura credenciales y
  abre tu primera sesión.
- [Guía de uso](using-agent.md): trabaja con el agente desde CLI o MCP y revisa
  propuestas antes de aplicarlas.
- [Desarrollo](development.md): prepara el entorno del proyecto, cambia el
  piloto y valida tus cambios.

## Manuales de comandos

Los detalles de opciones y configuración están en los [manuales de ASN](man_asn.md)
y en cada referencia enlazada desde el menú.

## Contexto SpecNative

El contexto canónico para contribuir vive en `spec-native/`. Consulta
`spec-native/workflows/IMPLEMENTATION.md` antes de ejecutar tareas de una
iniciativa.

# serve

## Propósito

Inicia el servidor de desarrollo de MkDocs y reconstruye las páginas al
detectar cambios.

## Uso

```bash
make serve
just serve
```

Abre en el navegador la URL local que informa MkDocs. Interrumpe el proceso con
Ctrl+C al terminar.
